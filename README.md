# Квиз-бот «Архетип вашего бренда»

Полный перенос веб-квиза в Telegram: те же 12 вопросов, те же 12 архетипов
по Юнгу, тот же промт для нейросети и та же кнопка на «Разбор проекта».
Бот бесплатный — работает только как лид-магнит, генерации картинок внутри
нет (это отдельный, более сложный и платный этап — если решите его
добавить, дайте знать).

## 1. Получить токен бота

1. Откройте в Telegram **@BotFather**
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

## 2. Установить и запустить

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен_сюда"
python bot.py
```

На Windows вместо `export` используйте:
```
set BOT_TOKEN=ваш_токен_сюда
```

Бот будет работать, пока запущен процесс `python bot.py`. Для постоянной
работы 24/7 его нужно разместить на сервере/хостинге (например, обычный VPS
за 200–300₽/мес, или бесплатный тариф на Railway/Render — подскажу, если
понадобится).

## 3. Что можно поменять без программиста

- **Ссылки на связь** — в начале файла `bot.py`, переменные
  `TELEGRAM_CONTACT_URL` и `MAX_CONTACT_URL`
- **Кодовое слово** — переменная `CODE_WORD`
- **Тексты вопросов/архетипов** — в словарях `QUESTIONS` и `ARCHETYPES`,
  структура один в один как в веб-версии квиза

## 4. Ограничения этой версии

- Прогресс квиза хранится в памяти процесса — если бот перезапустится
  посреди прохождения, придётся начать заново (для лид-магнита это не
  критично)
- Генерация картинок нейросетью не встроена — квиз только выдаёт готовый
  текстовый промт для копирования, как и на сайте
- Нет сбора аналитики (сколько прошли квиз, на каком вопросе бросили) — если
  захотите это отслеживать, можно добавить логирование в файл или таблицу
